§Tracking Documents) — the scope column is the *only* thing triage sees, so it must stay
accurate. If a doc's content grows past what its scope line describes, rewrite the line
(and bump `Updated`) in the same step that grows the doc. A stale scope silently hides the
doc from every future conversation.

ACTIVE docs govern current work. CLOSED docs settle past questions — never deleted, may be
reopened; consult them for cross-reference, but they do not govern current work.
